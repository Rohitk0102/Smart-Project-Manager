# Smart Project Manager

## 📦 How to Install Dependencies

**Windows:**
Double-click `install_dependencies.bat`

**Mac / Linux:**
Run the following in your terminal:
```bash
chmod +x install_dependencies.sh
./install_dependencies.sh
```

---

## 🚀 How to Run the Project

**Windows:**
Double-click `start.bat`

**Mac / Linux:**
Run the following in your terminal:
```bash
chmod +x start.sh
./start.sh
```

## 🌐 Application URL
Once the services are running, open your browser and go to:
**[http://localhost:5173](http://localhost:5173)**

> **⚠️ Note:** Please wait up to **5 minutes** for all services (Backend, AI Service, Frontend) to fully start before accessing the URL. The AI service may take a moment to load models.
